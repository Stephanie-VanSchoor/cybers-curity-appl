# 🔐 CyberLab — Apprendre la cybersécurité

## 📖 Présentation

CyberLab est une application éducative en HTML conçue pour apprendre les bases de la cybersécurité et découvrir le hacking éthique.

Elle s'adresse principalement aux débutants qui souhaitent comprendre comment protéger leurs comptes, leurs appareils et leurs données.

## ✨ Fonctionnalités

- 📚 **Cours interactifs** : découverte des bases de la cybersécurité, des réseaux et de la défense.
- 🔐 **Sécurité des comptes** : apprentissage des mots de passe robustes et du MFA (authentification multifacteur).
- 🎣 **Détection du phishing** : apprendre à reconnaître les messages frauduleux.
- 💻 **Terminal simulé** : découvrir des commandes et des notions informatiques.
- 🧠 **Quiz et exercices** : tester ses connaissances et apprendre grâce aux explications.
- 📈 **Progression** : suivre son apprentissage au fil des modules.

## 🚀 Installation et lancement

Aucune installation particulière n'est nécessaire.

1. Télécharge le fichier `CyberLab_Cybersecurite.html`.
2. Enregistre-le dans un dossier sur ton ordinateur.
3. Double-clique sur le fichier.
4. Ouvre-le avec un navigateur récent, comme Chrome, Firefox, Edge ou Safari.
5. Commence les cours et les exercices.

## 🛠️ Technologies utilisées

- HTML : structure de l'application.
- CSS : apparence et mise en page.
- JavaScript : interactions, quiz et exercices.
- LocalStorage : sauvegarde locale de la progression, si cette fonctionnalité est activée dans la version utilisée.

## 🎯 Objectifs pédagogiques

CyberLab permet de découvrir :

- Les principes fondamentaux de la cybersécurité.
- Les réseaux et les adresses IP.
- Les mots de passe et l'authentification multifacteur (MFA).
- Les tentatives de phishing.
- Les bonnes pratiques de protection des systèmes.
- Les bases du hacking éthique.

## ⚠️ Utilisation responsable

CyberLab est destiné à l'apprentissage et à la défense informatique.

Les exercices pratiques doivent être réalisés uniquement sur des systèmes personnels ou avec l'autorisation explicite de leur propriétaire.

Ne teste jamais les systèmes d'une autre personne ou organisation sans autorisation.

## 📌 Limites

CyberLab est une application éducative fonctionnant dans un navigateur. Les fonctionnalités et les exercices dépendent de la version du fichier HTML utilisé.

Le terminal pédagogique, lorsqu'il est simulé, ne remplace pas un véritable environnement Linux.
