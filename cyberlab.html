Laboratoire simulé

La console d'entraînement

Teste des commandes pédagogiques dans un faux terminal. Rien n'est exécuté sur ton ordinateur ou sur un réseau.

cyberlab@local:~
CyberLab Terminal v1.0\nEnvironnement simulé — aucune connexion réseau.\nTape « help » pour voir les commandes disponibles.\n

Commandes disponibles

help

Affiche les commandes d'apprentissage.

whoami

Affiche l'utilisateur fictif du labo.

network

Explique les notions IP, routeur et DNS.

check-password

Analyse un exemple de mot de passe fictif.

clear

Efface l'affichage du terminal.

Ce terminal est une simulation volontairement limitée. Il n'accepte pas de commandes système réelles.
